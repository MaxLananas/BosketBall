# Purchased 16x16 icon library

These source PNGs were supplied by the BosketBall owner and imported from the
`main` branch (`8020c6b`) without modifying their pixels. The resource-pack
generator reads them through `tools/premium_ui_overhaul.py`, normalizes their
alpha to the binary alpha used by BosketBall's native 16x16 item sprites, and
maps them to menu, dunk, lobby-prop and collector-tag model IDs.

Do not delete unused files from this directory merely because a particular
release does not map them yet: this is the owner's purchased source library and
keeps future icon work reproducible.
