Generated by `python3 tools/icon_inventory.py --markdown`. Do not edit by hand:
re-run the command. This file is the contract Agent 5 (ball models) and
Agent 3 (interfaces) build against.

## How to read this

| column | meaning |
|---|---|
| `code` | how many times the id appears in `src/main/java` |
| `files` | how many main-source files mention it |
| `light` | where the brightest tone sits, measured by `icon_language.light_vector` |
| `ink` | the silhouette-edge ink colour |

An icon is usable only when the texture, `models/item/<id>.json` and
`items/<id>.json` all exist. Anything else is invisible to the game.
